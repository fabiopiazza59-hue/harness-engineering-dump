# Data dictionary for data.csv

- `id`: record identifier
- `age`: age in years
- `sex`: sex (0 = female, 1 = male)
- `bmi`: body-mass index (kg/m^2)
- `treatment`: study group: unfertilised or fertilised
- `baseline`: baseline value of the outcome on the same scale
- `biomass`: above-ground biomass (g/m^2)
- `event`: binary clinical or study event at follow-up (1 = yes)
