# Data dictionary for data.csv

- `id`: record identifier
- `age`: age in years
- `sex`: sex (0 = female, 1 = male)
- `height_cm`: height in centimetres
- `weight_kg`: weight in kilograms
- `site`: study site identifier (1-4)
- `condition`: study group: placebo or caffeine (free-text entry)
- `baseline`: baseline value of the outcome
- `rt_ms`: reaction time (ms) on the Stroop task
- `rt_ms_post`: reaction time (ms) on the Stroop task at the second assessment
- `event`: binary study event (1 = yes)
- `enrol_date`: enrolment date (YYYY-MM-DD)
- `last_contact_date`: date of event or last contact (YYYY-MM-DD)
- `biomarker_1..biomarker_6`: six standardised biomarker levels
