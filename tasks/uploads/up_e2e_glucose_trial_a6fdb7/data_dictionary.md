- `id`: participant identifier (integer, one row per participant)
- `age`: age in years (float); analysis restricted to 18-80 inclusive
- `sex`: binary sex indicator (0/1)
- `bmi`: body mass index (kg/m^2)
- `diet`: group membership, `mediterranean` (intervention) or `usual` (comparator)
- `baseline`: baseline fasting glucose (mg/dL)
- `glucose_fu`: fasting glucose (mg/dL) at follow-up — primary outcome; missing values excluded
- `event`: binary event indicator (0/1), not used in the primary analysis
